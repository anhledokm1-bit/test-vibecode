# Vibe Coding Interactive CV & Portfolio

Trang CV cá nhân phong cách **Vibe Coding** tương tác cao, được xây dựng và hoàn thiện bằng **Google Antigravity** theo phương pháp luận **Superpowers**.

## ✨ Tính năng nổi bật

- **Giao diện Vibe Coder hiện đại**: Dark mode cao cấp, hiệu ứng neon glow (Cyan / Purple / Emerald), font JetBrains Mono & Inter, thẻ kính mờ (Glassmorphism).
- **Chế độ Sửa Trực Tiếp (Live In-Browser Edit)**: Cho phép click trực tiếp vào văn bản để chỉnh sửa thông tin cá nhân và lưu trữ an toàn trong `localStorage`.
- **Bộ lọc dự án & Tech Radar**: Lọc dự án theo lĩnh vực (Frontend, Full-Stack, AI) hoặc bấm vào bất kỳ thẻ công nghệ nào để lọc.
- **Project Deep Dive Modal**: Pop-up xem chi tiết kiến trúc, công nghệ và liên kết repository.
- **Terminal CLI tích hợp**: Gõ lệnh thực tế (`help`, `skills`, `projects`, `edit`, `save`, `print`, `clear`).
- **Xuất PDF chuẩn chỉnh**: Nút "In / PDF" tự động dọn dẹp viền chỉnh sửa và chuyển về phong cách trang giấy trắng thanh lịch cho nhà tuyển dụng.

## 🚀 Hướng dẫn mở và xem

Chỉ cần mở file `index.html` bằng bất kỳ trình duyệt nào:
```bash
open index.html
```
